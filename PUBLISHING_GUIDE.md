# Publish Vandita's GitHub Portfolio

## Part 1 — Create the profile website repository

1. Sign in to GitHub.
2. Select **New repository**.
3. Name it exactly `YOUR_GITHUB_USERNAME.github.io`.
4. Choose **Public** and create the repository.
5. Upload `index.html`, `styles.css`, `README.md`, and the complete `assets` folder from this package.
6. Commit the files to the `main` branch.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose `main`, select `/ (root)`, and save.
10. Wait a few minutes, then open `https://YOUR_GITHUB_USERNAME.github.io/`.

## Part 2 — Upload the Netflix project

1. Create a second public repository named `netflix-content-program-analytics`.
2. Upload the contents of the Netflix GitHub ZIP previously prepared for you.
3. Do not upload the raw Netflix CSV if its source license or attribution does not permit redistribution.
4. Confirm that the repository home page displays its README, screenshots, methodology, code, SQL, workbook, and presentation.
5. Copy the repository URL.

## Part 3 — Connect the two repositories

1. Edit this portfolio's `index.html`.
2. Add a **View GitHub repository** button in the featured project section.
3. Paste the Netflix repository URL into that button.
4. Verify the LinkedIn and GitHub links in the Connect section, then add your professional email and résumé link when ready.
5. Commit the update.

## Part 4 — Add the forecasting project repository

1. Create a third public repository named `sales-operations-forecast-optimization`.
2. Upload the anonymized presentation from this package's `assets` folder.
3. Add a README that explains the 25-month demand analysis, forecast-accuracy comparison, ARIMA test, and purchase-order model.
4. Add the repository URL to the forecasting case-study section in `index.html` if you want a second GitHub button.
5. Confirm that no former company or client branding appears in any public file.

## Part 5 — Finish the GitHub profile

1. Open your GitHub profile and select **Customize your pins**.
2. Pin `netflix-content-program-analytics` first.
3. Pin `sales-operations-forecast-optimization` second.
4. Pin `YOUR_GITHUB_USERNAME.github.io` third.
5. Pin your strongest SQL and Power BI projects next.
6. Add the portfolio URL to the **Website** field in your GitHub profile.
7. Use the headline: `Business Intelligence & Data Analytics | SQL | Power BI | Forecasting | ETL`.
