# Vandita Kulkarni — GitHub Pages Portfolio

This folder is a no-build static portfolio. It is ready for GitHub Pages.

## Personalize before publishing

1. Open `index.html`.
2. In the **Connect** section, verify your LinkedIn and GitHub profile links, then add an email and résumé link when ready.
3. Add the Netflix repository link to the featured-project section after uploading the separate `netflix-content-program-analytics` repository.
4. Keep `assets/Vandita_Sales_Operations_Planning_Business_Case.pptx` in the repository so the forecasting-project download works.
5. If desired, add a professional photo under `assets/` and reference it from the About section.

## Publish

1. Create a public repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload everything **inside this folder** to the repository root.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Your portfolio will appear at `https://YOUR_GITHUB_USERNAME.github.io/`.

## Recommended repository order

Pin these repositories after publishing:

1. `netflix-content-program-analytics`
2. `sales-operations-forecast-optimization`
3. `YOUR_GITHUB_USERNAME.github.io`
4. Your strongest SQL or Power BI project
